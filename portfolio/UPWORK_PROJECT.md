# PayPilot — Invoice & Payment Automation Dashboard

## Project title
PayPilot — Invoice & Payment Automation Dashboard

## My role
Full-Stack Python Developer & Automation Engineer

## Project description
Built PayPilot, a full-stack invoice and payment operations application using Python, FastAPI, SQLAlchemy and JavaScript. Features include natural-language invoice drafting, line-item totals, private customer invoice pages, printable invoices and receipts, payment timelines, receivables aging, reminder previews and duplicate-safe automation. Implemented PayPal Sandbox order/capture and verified-webhook integration, isolated visitor demos, secure sessions and MySQL TLS support. Deployed the interactive demo on Render with automated tests in GitHub Actions.
