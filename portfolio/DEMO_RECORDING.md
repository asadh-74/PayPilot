10–25s: Show currency-separated dashboard totals and Collections aging. “Each visitor receives fictional, isolated demo data.”

25–45s: Create an invoice: “Website design package”; add Design (quantity 2, unit price 125.50) and Hosting setup (quantity 1, unit price 49.00). Total: USD 300.00. Use buyer@example.com. Show the total is calculated from items.

45–60s: Click Invoice on that row. Open the customer page. Show line items, sandbox label, due date, reference and Print / Save PDF.

60–75s: Return to the workspace. Simulate capture. Open Details to show the invoice and capture timeline. Open its receipt. Explain that public demo captures are simulations.

75–90s: Run the overdue batch twice. Show the second run creates zero duplicates, and messages remain unsent previews. Close with the source and public demo links.

Before recording: close other tabs and private notifications; show no credentials, Gmail address or provider configuration. Do not claim that simulated capture is a real PayPal payment. The public host may need time to wake. Demo storage may reset on deployment.
